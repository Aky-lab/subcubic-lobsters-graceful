# Graceful labelings of subcubic lobsters

A private research manuscript and its verification supplement. The manuscript describes AI contributions and the status of the computational checks. Project contact: Akram Younso.

Read manuscript.pdf for the proof. Extract supplement.zip and follow the enclosed README.md to check the certificate. The LaTeX source is manuscript.tex.

The [Lean proof](lean/README.md) formalizes the complete graph theorem, including the graph-to-word reduction, the exact certificate, and the labeling construction. The main statement is [every_subcubic_lobster_is_graceful](lean/GraphTheorem.lean). Three finite checks use compiled evaluation. The deposited v1 manuscript and supplement predate the formalization.
